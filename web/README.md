# Betpawa Virtual Games Tracker - Web App

✅ **Complete React web app ready to install on your phone!**

## 🚀 Quick Start

```bash
cd web
npm install
npm start
```

Then open http://localhost:3000

## 📱 Install on Phone

### iOS (iPhone):
1. Open in Safari
2. Tap Share → "Add to Home Screen"
3. Tap Add

### Android:
1. Open in Chrome
2. Tap menu (⋮) → "Install app"
3. Confirm

## ✨ Features

✅ Track wins/losses
✅ View real-time stats
✅ See bet history
✅ Export as CSV
✅ Works offline
✅ Mobile-optimized

## 📊 Screens

- **Home** - Dashboard with summary
- **Add** - Record new bets
- **History** - All your bets
- **Stats** - Detailed analytics
- **Settings** - Export & manage data
