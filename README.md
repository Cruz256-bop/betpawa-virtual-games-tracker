# Betpawa Virtual Games Tracker

A React Native mobile application to track your Betpawa virtual games betting outcomes, analyze patterns, and monitor your performance.

## Features

✅ **Track Bets** - Record each bet with game type, stake, odds, and outcome
✅ **Win/Loss Records** - Log whether each bet was a win or loss
✅ **Bet History** - View all your past bets with detailed information
✅ **Statistics** - Analyze your performance with comprehensive stats
- Total bets placed
- Win rate percentage
- Total staked and winnings
- Profit/loss calculation
- Performance by game type

✅ **Dashboard** - Quick overview of your betting summary
✅ **Data Export** - Export your betting data as CSV
✅ **Data Management** - Clear data and manage your records

## Installation

### Prerequisites
- Node.js (v14 or higher)
- Expo CLI: `npm install -g expo-cli`
- Expo Go app on your phone (iOS/Android)

### Setup

1. Clone the repository
```bash
git clone <repository-url>
cd betpawa-virtual-games-tracker
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Scan the QR code with Expo Go app on your phone

## Usage

### Adding a Bet
1. Navigate to the "Add Bet" tab
2. Select the game type (Football, Horse Racing, Basketball, Tennis, Other)
3. Enter your stake amount
4. Enter the odds you picked
5. Select the outcome (Win or Loss)
6. If you won, enter your winnings amount
7. Optionally add notes
8. Tap "Add Bet"

### Viewing History
- Go to the "History" tab to see all your recorded bets
- Pull down to refresh
- Tap delete to remove a bet

### Checking Statistics
- Navigate to the "Stats" tab
- View overall performance metrics
- See performance breakdown by game type

### Managing Data
- Go to "Settings" to export data as CSV
- Clear all data if needed (irreversible)
